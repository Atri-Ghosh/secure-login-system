# Secure Login Portal - Internship Weekly Task

A responsive login interface developed as part of web development internship tasks, focusing on modern UI design, form validation, and authentication concepts.

## 🚀 Features
* **HTML5 & CSS3:** Modern, centered card layout with smooth transitions and error states.
* **Email Regex Validation:** Instant pattern matching for standard email formats.
* **Real-time Password Strength Meter:** Dynamic color-coded bars tracking length, uppercase letters, numbers, and special characters.
* **Password Visibility Toggle:** Show/hide password eye icon functionality using FontAwesome.
* **Session Persistence:** Keeps the user signed in across browser sessions using `localStorage` and `sessionStorage`.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Flexbox, Variables, Transitions)
* Vanilla JavaScript (DOM Manipulation, Regex, Web Storage API)
